AutoStrafeTool2 —— 安装说明
====================================================================
版本：2.7.3
类型：L4D2 服务端 SourceMod 插件（空中自动加速 + 连跳 + 摆动 + 避让）
作者：ST2ange、大肥鱼

    安装说明.txt    就是这个，讲怎么装

--------------------------------------------------------------------
一、安装前确认
--------------------------------------------------------------------
1. 已装 SourceMod 1.12 或更新版本
   检查：控制台输入 sm version，能看到版本号
2. 已装 DHooks（SourceMod 1.10 起已内置，无需单独下）
   检查：控制台输入 sm exts list，列表里有 "DHooks"

--------------------------------------------------------------------
二、安装（三步）
--------------------------------------------------------------------
1. 把压缩包里的 addons 和 cfg 两个文件夹，直接拖进：

       ...\Left 4 Dead 2\left4dead2\

   合并覆盖即可。装完应该是这样：

       left4dead2\addons\sourcemod\plugins\AutoStrafeTool2.smx
       left4dead2\addons\sourcemod\gamedata\AutoStrafeTool2.games.txt
       left4dead2\cfg\sourcemod\AutoStrafeTool2.cfg

   gamedata 那个文件不能少 —— 它提供 AirAccelerate 的函数地址，
   缺了插件还能加载，但"引擎真值"失效，加速效果会明显变差。

2. 开一局游戏，控制台输入：

       sm plugins list

   列表里应该能看到：

       [SM]  AutoStrafeTool2

3. 进游戏后聊天框输入：

       !asm

   弹出菜单就说明装好了。

--------------------------------------------------------------------
三、【最重要的一个指令】!asm —— 打开插件菜单
--------------------------------------------------------------------
    !asm    打开游戏内菜单

    打开后屏幕中间出现两页菜单，直接按数字键切换，不用记任何指令：

        第 1 页（功能）
            1. 普通模式        [开]
            2. 八向模式        [关]
            3. 整跳模拟        [开]
            4. 半跳模拟        [关]
            5. 自动连跳        [开]
            6. 加速力度  4档  >
            7. 进服自动开加速  [开]
            8. 进服自动开连跳  [开]
            9. 下一页  >  模块设置

        第 2 页（模块 + 常用开关）
            1. 跳跃设置  >   挂载 / 宽限 / 接管条件
            2. 避障设置  >   贴墙硬拐 / 僵尸特感 Witch 避让
            3. 强拐设置  >   甩视角强拐
            4. 整跳设置  >   摆动 / 折返 / 镜头
            5. 接管视角 [开]
            6. 避障     [开]
            7. 强拐     [关]
            8. 查看指令说明
            9. 上一页  <  主菜单

    按 0 退出菜单。所有设置都能在菜单里完成，装完先按 !asm 看一眼。

    注意：Source 引擎的菜单会释放鼠标，开着菜单时视角不能转。
    这是站定设置用的，别边跑边开。

--------------------------------------------------------------------
四、四个基础模式分别干什么
--------------------------------------------------------------------
插件一共四种模式，互斥、后选的覆盖前一个，再选一次就关闭。
装上默认是关的，要自己开一个。

    !as        普通模式
               空中松开方向键，自动沿【视角方向】加速。
               最像原版空速，只在你不动方向键时接管，
               适合想保留手感、只补空中加速的人。

    !asbx      八向模式
               沿【视角 + 方向键】加速，八个方向随便衔接。
               按 W/A/S/D 任意组合都能加速，转换方向不断速，
               适合想在地图里自由转向跑图的人。

    !mn        整跳模拟
               模拟真人的【前后整跳 / 旋转跳 / 高低差摆动】。
               每跳先往一侧摆、过顶点折返，收尾侧刚好是下一跳起手侧，
               所以跨跳是连续的，看起来像真人在空中摆身子。

    !mnbt      半跳模拟
               模拟【前后半跳】。每一跳都从头重新摆一遍，相位不跨跳。
               观感比整跳"碎"一点，但更接近某些人的操作习惯。

--------------------------------------------------------------------
五、其它指令
--------------------------------------------------------------------
    !aszl     指令清单（9 行，看一眼就全懂了）
    !aszt     当前状态面板（模式 / 力度 / 速度 / 本跳 / 强拐 / 引擎参数）
    !ascvar   按分组列出全部可调 cvar
    !ab       自动连跳（按住空格，落地自动再跳）
    !asd 1-5  加速力度档位（1 最弱 ≈10000/跳，5 最强 13980/跳）
    !asz 数值 加速力度数值模式（1-13980 自定义）

    控制台用同名指令，把开头的 ! 换成 sm_ 即可：
    sm_asm / sm_aszt / sm_aszl / sm_as / sm_ab / sm_asd / sm_asz

--------------------------------------------------------------------
六、配置文件
--------------------------------------------------------------------
    cfg/sourcemod/AutoStrafeTool2.cfg

所有参数都是 sm_autostrafe_ 开头，例如：

    sm_autostrafe_mn_cam "0"          // 关掉镜头接管（觉得视角被拽就设 0）
    sm_autostrafe_avoid_mob "1"       // 打开僵尸 / 特感 / Witch 避让
    sm_autostrafe_flick_rate "200"    // 甩视角强拐的触发门槛
    sm_autostrafe_mn_fwd_loop "0"     // 长滞空只折返一次（落地不抽，高低差会偏）

改完重进地图生效，或控制台：

    sm plugins reload AutoStrafeTool2

--------------------------------------------------------------------
七、卸载
--------------------------------------------------------------------
删掉这三个文件即可：

    addons/sourcemod/plugins/AutoStrafeTool2.smx
    addons/sourcemod/gamedata/AutoStrafeTool2.games.txt
    cfg/sourcemod/AutoStrafeTool2.cfg

--------------------------------------------------------------------
八、常见问题
--------------------------------------------------------------------
Q: sm plugins list 里 AutoStrafeTool2 是红色的（error）
A: 大概率 gamedata 没放对位置。确认
   addons/sourcemod/gamedata/AutoStrafeTool2.games.txt 存在，
   然后 sm plugins reload AutoStrafeTool2 看控制台报什么错。

Q: 插件正常加载，但加速没效果
A: 三个原因按顺序查：
   1. 没开模式 —— 先 !asm 里选一个，或直接 !as / !mn
   2. 服务器 sv_airaccelerate 是 0 —— 控制台 sm_autostrafe_aa 100 试试
   3. 人在空中才生效，地面跑不会加速

Q: 用了 !mn 之后视角被拽得难受
A: 这是"接管视角"（mn_cam）。设 sm_autostrafe_mn_cam 0 就不碰视角了，
   加速完全不受影响，只是画面不跟着摆。菜单第 2 页第 5 项也能关。

Q: 以前装过旧版 sm_autostrafe_l4d2.smx，要不要删
A: 要删。两个同时存在会各自接管一次，行为会乱。
   同时把旧的 cfg/sourcemod/sm_autostrafe_l4d2.cfg 也删掉（内容重复）。
